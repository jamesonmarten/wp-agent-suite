AI-powered WordPress speed audit. Get a prioritized Core Web Vitals fix list — formatted as a $499 client proposal.

== Description ==

**DC Speed Optimizer** uses GPT-4o to generate a comprehensive Core Web Vitals and performance audit for any WordPress site. Includes simulated LCP, INP, and CLS scores, a prioritized issue list, and a ready-to-send implementation quote.

= What it does =
* Simulates PageSpeed Insights + GTmetrix analysis
* Produces 8–12 prioritized issues with impact level and time savings
* Covers image optimization, caching, database, and render-blocking resources
* Outputs a $499 proposal-ready report in under 60 seconds

= How to monetize =
* Offer as a **$499 speed optimization service** using the report as your proposal
* Run for every new client site as part of **onboarding**
* Bundle into care plans to **justify higher monthly fees**
* Run on prospect sites as a **cold outreach tool**

== Installation ==

1. Upload `dc-speed-optimizer` to `/wp-content/plugins/`
2. Activate the plugin
3. Go to **Speed Optimizer → Settings** and enter your OpenAI API key
4. Enter a site URL and generate your first audit

== Frequently Asked Questions ==

= Are the scores real PageSpeed data? =
No — the agent simulates realistic performance scores for consulting and proposal purposes. For real metrics, pair with Google PageSpeed Insights or GTmetrix.
