AI-curated WordPress plugin stacks for any business type. Get a hand-picked, conflict-checked recommendation report with an implementation quote.

== Description ==

**DC Plugin Recommender** uses GPT-4o to build a complete, curated plugin stack for any business — with compatibility notes, setup order, cost breakdown, and a ready-to-send implementation proposal.

= What it does =
* Accepts business type, goals, budget, and tech level
* Recommends plugins for SEO, security, performance, forms, e-commerce, and more
* Flags known plugin conflicts
* Provides an installation priority order
* Generates a $297–$997 implementation quote automatically

= How to monetize =
* Send as a **free pre-sales deliverable** to close new clients
* Charge **$297–$997** to implement the recommended stack
* Use affiliate links for premium plugins for **passive commissions**
* Offer as a standalone **$97 consulting report** for DIY clients

== Installation ==

1. Upload `dc-plugin-recommender` to `/wp-content/plugins/`
2. Activate the plugin
3. Go to **Plugin Recommender → Settings** and enter your OpenAI API key
4. Navigate to **Plugin Recommender** and generate your first stack

== Frequently Asked Questions ==

= Does it check live plugin compatibility? =
The agent uses GPT-4o's training knowledge to flag known conflicts between popular plugins. For critical production sites, always test in a staging environment.

= Where do I get an OpenAI API key? =
Visit https://platform.openai.com/api-keys
