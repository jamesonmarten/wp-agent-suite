== Description ==

**DC Child Theme Builder** uses GPT-4o to generate production-ready CSS snippets, PHP functions, and complete child theme scaffolds for any WordPress customization request. Includes theme-specific notes for Divi, Elementor, Astra, GeneratePress, Kadence, OceanWP, and Avada.

= What it does =
* Accepts a plain-English description of the desired change
* Generates complete, commented CSS with desktop and mobile breakpoints
* Outputs PHP snippets for functions.php where needed
* Provides a full child theme scaffold (style.css + functions.php)
* Flags known conflicts with page builders and caching plugins
* Includes step-by-step implementation instructions and a testing checklist

== Installation ==

1. Upload `dc-child-theme-builder` to `/wp-content/plugins/`
2. Activate the plugin
3. Go to **Child Theme Builder → Settings** and enter your OpenAI API key
4. Describe your customization and generate your first snippet

== Frequently Asked Questions ==

= Is the generated code production-ready? =
The code is written to be production-ready and well-commented. Always test in a staging environment before deploying to production, especially for complex customizations.

= Which themes are supported? =
The agent has specific knowledge of Divi, Elementor (Hello), Astra, GeneratePress, Kadence, OceanWP, Avada, Flatsome, and Neve. Generic CSS and PHP will be generated for all other themes.
